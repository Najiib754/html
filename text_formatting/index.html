HTML
HyperText Markup Language used to structure content on the web.
Element
A complete HTML unit consisting of a start tag, content, and an end tag.
Tag
A keyword enclosed in angle brackets used to define elements.
Attribute
Provides additional information about an HTML element, placed inside the start tag.
Head
The section of HTML that contains metadata like title, links, and scripts.
Body
The part of HTML where visible content is displayed in the browser.
Heading
Defines titles or subtitles using tags from h1 to h6.
Paragraph
Represents a block of text using the p tag.
Anchor
Used to create hyperlinks with the a tag.
Image
Embeds images into a webpage using the img tag.
List
A collection of items, can be ordered (ol) or unordered (ul).
Form
Used to collect user input with fields like text, email, and buttons.
Input
An element inside forms to receive user data.
Button
A clickable element used to submit forms or trigger actions.
Div
A container element used for grouping content.
Span
An inline container used to style small parts of text.
Semantic Tags
Tags like header, footer, article that give meaning to content.
Meta Tag
Provides metadata such as character set and viewport settings.
Link Tag
Used to connect external resources like CSS files.
Script Tag
Used to include JavaScript code in an HTML document.
